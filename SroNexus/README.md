## 📋 Overview

SroNexus is a **complete Silkroad Online server emulator** that combines:
- **Full eSRO Server Emulator** (based on SDClowen/eSRO)
- **Advanced Management System** (C# WPF + C++ Core)
- **500+ Configurable Features**
- **Visual Content Editor** (No SQL required)
- **Complete Player Support** (Registration, Login, Gameplay)

This is a production-ready server that can host real players!

## 🚀 Installation & Setup

### Prerequisites
- Windows 10/11 (64-bit)
- Visual Studio 2022
- .NET 6.0 Runtime
- SQL Server or MySQL
- 8GB RAM minimum
- 10GB free disk space

### Quick Installation

1. **Clone the repository**
```bash
git clone https://github.com/yourusername/SroNexus.git
cd SroNexus
```

2. **Setup Database**
```bash
cd Database
# Run create_databases.sql in your SQL Server/MySQL
# Import all table structures
```

3. **Build the Server**
```bash
# Open SroNexus.sln in Visual Studio
# Build Solution (Ctrl+Shift+B)
# Choose Release x64
```

4. **Configure Server**
```bash
# Edit SroNexus/appsettings.json
# Set your database connection
# Configure server paths
# Set IP and ports
```

5. **Start the Server**
```bash
# Run SroNexus.exe
# Click "Start All Servers"
# Monitor the dashboard
```

## 🎮 Connecting Players

### Client Configuration
1. Use a compatible Silkroad Online client
2. Edit the client to point to your server IP
3. Distribute the modified client to players

### Default Ports
- LoginServer: 15779
- AgentServer: 15780
- GatewayServer: 15781
